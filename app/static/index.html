YouTube Authentication (Cookies)

Fitur "Login via OAuth" telah diblokir permanen oleh pihak YouTube (Error: Login with OAuth is no longer supported).

Untuk menghindari pemblokiran/bot detection, Anda harus menggunakan metode cookies.txt.

  • Install ekstensi "Get cookies.txt LOCALLY" di Google Chrome PC Anda.
  • Buka youtube.com, klik ikon ekstensi, lalu Export.
  • Upload file cookies.txt tersebut ke Kaggle, lalu atur agar yt-dlp membacanya (tambahkan --cookies cookies.txt pada app/config.py atau media.py).
